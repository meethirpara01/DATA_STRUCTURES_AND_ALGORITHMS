# Why We Can't Do `arr = arr + 1;` in C++?

## 📌 Introduction

In C++, you might wonder why trying to increment an array like this:

```cpp
arr = arr + 1;
```

causes a **compilation error**. This README explains the reason behind this behavior and the correct way to navigate through array elements using pointers.

---

## 🧠 Core Concept

In C++, the **name of an array** (like `arr`) is actually a **constant pointer** to the **first element** of the array. This pointer **cannot be modified**.

So, when you write:
```cpp
arr = arr + 1;
```
You’re attempting to change the address that `arr` refers to — which is not allowed because `arr` is a **constant pointer**.

---

## ❌ Why It Fails

Consider the following example:

```cpp
int arr[5] = {1, 2, 3, 4, 5};
arr = arr + 1; // ❌ Compilation Error
```

- `arr` is not a normal pointer; it’s a constant that refers to the start of the array.
- You **cannot reassign** `arr` to point somewhere else.

---

## ✅ Correct Way Using Pointer

If you want to perform pointer arithmetic, you can use a separate pointer:

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* ptr = arr;  // ✅ Pointer to the first element

ptr++;           // ✅ Now points to the second element

std::cout << *ptr << std::endl; // Output: 2
```

In this case:
- `ptr` is a **non-const pointer** and can be modified.
- `ptr++` increments the pointer to point to the next element in the array.
- `*ptr` dereferences the pointer to access the value.

---

## ✅ Summary

- `arr` is a **constant pointer**, so you **cannot modify** it with `arr = arr + 1;`.
- Use a separate **non-const pointer** like `int* ptr = arr;` if you need to move through the array using pointer arithmetic.

---

## 🧪 Recap Table

| Expression       | Valid? | Explanation |
|------------------|--------|-------------|
| `arr = arr + 1;` | ❌     | `arr` is a constant pointer |
| `int* ptr = arr; ptr++;` | ✅ | `ptr` is a modifiable pointer |
| `*(arr + 1)`     | ✅     | Accesses the second element using pointer arithmetic |
