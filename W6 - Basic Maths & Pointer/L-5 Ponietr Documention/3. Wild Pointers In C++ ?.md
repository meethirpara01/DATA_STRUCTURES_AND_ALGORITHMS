# Wild Pointers in C++

## 📌 Introduction

A **wild pointer** in C++ is a pointer that either:
- Has **not been initialized**, or
- Points to **deallocated memory**.

Such pointers do **not point to a valid memory location**, and **accessing or dereferencing them leads to undefined behavior**. Wild pointers are dangerous and can crash your program or produce unpredictable results.

---

## 💥 Common Scenarios That Cause Wild Pointers

### 1. ❌ Uninitialized Pointers

```cpp
int* ptr;
std::cout << *ptr << std::endl; // ❌ Undefined behavior
```

- `ptr` is declared but never initialized.
- It holds a **garbage address**.
- Dereferencing it leads to **unpredictable behavior**.

---

### 2. ❌ Dereferencing After Deletion

```cpp
int* ptr = new int;
delete ptr;
std::cout << *ptr << std::endl; // ❌ Undefined behavior
```

- Memory was allocated with `new`, then freed with `delete`.
- But we still try to access the pointer after deletion.
- This is a classic **use-after-free** case.

---

### 3. ❌ Pointers to Non-Existent Variables

```cpp
int* ptr = &x; // ❌ 'x' not declared!
std::cout << *ptr << std::endl;
```

- The pointer is referencing a **non-existent or undeclared variable**.
- Dereferencing it results in undefined behavior.

---

## ✅ How to Avoid Wild Pointers

1. **Always initialize pointers**:
```cpp
int* ptr = nullptr; // ✅ Safe to declare
```

2. **After deleting a pointer, reset it**:
```cpp
delete ptr;
ptr = nullptr; // ✅ Prevents it from becoming wild
```

3. **Check before dereferencing**:
```cpp
if (ptr != nullptr) {
    std::cout << *ptr << std::endl;
}
```

4. **Only delete pointers allocated with `new`**, never stack or random memory addresses.

---

## 🔒 Summary

| Issue                              | Solution                           |
|-----------------------------------|------------------------------------|
| Uninitialized pointer             | Initialize to `nullptr`            |
| Dereferencing after `delete`      | Set pointer to `nullptr` after delete |
| Pointer to non-existent variable  | Ensure variable exists and is valid |
| Wild pointer access               | Always validate before use         |
